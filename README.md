# GitHub Pages Portfolio

This folder is a ready-to-deploy static portfolio site for GitHub Pages.

## Deploy (recommended)

1. Create a public repo named `evansmakori.github.io` on GitHub.
2. Copy everything from this folder into the repo root.
3. Commit + push to `main`.
4. In GitHub: Settings -> Pages -> Build and deployment -> Deploy from a branch -> `main` / root.

Your site will publish at: `https://evansmakori.github.io/`

## Contact email

Email is currently set to `evansmakori252@gmail.com` in `index.html`.

## (Optional) Add a resume

1. Add `assets/resume.pdf`
2. Add a button/link in `index.html` to `assets/resume.pdf`

## Customize SEO

If you use a custom domain, update these in `index.html`:

- `canonical`
- `og:url`
- `og:image` (hosted image URL)

Also update `sitemap.xml`.
